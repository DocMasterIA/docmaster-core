r=c.execute('''
  SELECT status, COUNT(*) FROM pncp_ingest_queue
  WHERE task_type='contract_items' GROUP BY status
''').fetchall()

proc=sum(n for s,n in r if s=='processing')

"

13. LIMIARES — INTERPRETAÇÃO RÁPIDA
================================================================================

items_backlog worker (pending+processing contract_items):
  < 3000  → cruzeiro (catálogo pode rodar)
  >= 3000 → drenagem (catalog_ok=0, items_ok=40)

pending total:
  < 4000  → ok
  4000-5000 → atenção
  > 5000  → fila alta; verificar processing preso + deploy código

sem_itens (contratos sem linhas em pncp_itens):
  < 500   → ok
  > 2000  → catálogo >> itens (lag)

scopes_paused:
  0-10    → normal
  > 15    → considerar reativar json_invalid ou reduzir carga

total_itens subindo + pending caindo = saudável
